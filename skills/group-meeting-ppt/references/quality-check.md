# 硕士组会 PPT 交付验收清单

> 制作方内部使用的验收明细，补充 SKILL.md，不是默认交付的报告模板。只记录实际完成的检查；不适用项跳过，未执行项如实说明，不另要求用户勾选或确认。

## 内容与事实

- [ ] 页数、语言、必讲内容与需求一致，封面和附录计数清楚。
- [ ] 汇报主线清楚，各页信息适合目标听众。
- [ ] 数据、单位、指标方向、计算结果与材料一致。
- [ ] 公式、术语、图号、文献作者与年份正确。
- [ ] 事实、假设、预期结果和计划没有混淆。
- [ ] 关键结论有证据，缺失内容标为待补。
- [ ] 新项目没有残留模板中的旧姓名、单位、日期、主题和结果。
- [ ] 需要观众看到的来源与限定条件已在页面保留，其他出处可在备注、讲稿或内部来源记录找到。

## 组会内容检查（不适用项注明）

- [ ] 本次组会类型明确，背景和重点内容的篇幅适合本次目标。
- [ ] 提供过上次组会反馈时，已交代本次落实情况和新增工作。
- [ ] 具体工作有证据，避免只罗列“阅读文献、改进方法、开展实验”等活动。
- [ ] 实验或计算对比有必要的设置、指标与基线信息，已知的条件差异明确说明。
- [ ] 关键图表解释了现象与结论，原因假设没有写成已验证事实。
- [ ] 如有不理想结果，已如实记录现象、排查与未解决的问题。
- [ ] 论文作者的结果、本人复现与个人理解明确区分。
- [ ] 本次要求计划与讨论时，内容具体，时间没有被写成已确认承诺；只要求已完成工作时未扩写未来工作。

## 理解检查（对着实际页面执行）

- [ ] 主要内容页能说明听众要理解什么，必要的定义和判断标准已在使用前或就近交代。
- [ ] 方法图的输入、输出、串并联、残差与汇合关系可追踪，箭头有明确起终点，没有悬空的关键分支。
- [ ] 图中的主要关系与真实实现或论文相符；简化范围清楚，没有把示意误画成错误计算关系。
- [ ] 关键公式的符号与图中对象对应，关键项的作用能找到解释。
- [ ] 结果图给出比较条件、参照、具体观察位置和可支持的判断，图旁文字不是单纯重复通用定义。
- [ ] 图、表、标注与结论互相支持，重复呈现同一指标有明确目的。
- [ ] 新方法或尝试与前文问题有清楚联系，没有补造实验动机或原因。
- [ ] 逐页可以按实际页面复述关键关系；不能仅依靠大段讲稿填补页面缺失。

上述检查是制作方自检。真实听众是否理解，未获得反馈时不能声称已经验证。

## 逐页视觉检查

- [ ] 每页已经实际渲染并查看，包括附录。
- [ ] 没有文字溢出、非预期重叠、遮挡、截断或空白图像。
- [ ] 字体能正确显示，正文与图表标签适合投影阅读。
- [ ] 标题、正文、页码、边距与所选模板协调。
- [ ] 章节名、本页主题、正文和图表说明有清楚层级，没有多层大粗字争夺注意力。
- [ ] 使用编号页眉时，白色数字完整落在蓝色底块内；底条、图例、浅虚线和重点标注的实际显示已检查。
- [ ] 未另行指定时，以老师项目 PPT 为主视觉参考，蓝色页眉、浅蓝主题条和证据配解释的层级得到体现。
- [ ] 代表页在全稿展开前已渲染，与选定参考页按相同画布宽度并排查看；有明显构图差距时已修正。全稿检查也沿用相应参考，不能仅检查蓝色是否一致。
- [ ] 导航形状、主题条长度、主体分区、图文比例和字体层级与选定参考相符；调整有当前内容依据。参考可访问时没有跳过看图，仅有文字规则时已说明限制。
- [ ] 页面空间分配与内容相称：没有一边大幅空置、一边标签过小或解释分散的问题；相关图、公式、条件和判断形成连续阅读顺序。
- [ ] 图表已明确设置坐标、刻度、线条、图例及字体；没有直接沿用与参考明显不协调的默认图表外观。公式在合适运算位置换行，表达式未被文本框宽度截断。
- [ ] 图片清晰且比例正确，坐标轴、图例和必要标签没有被裁掉。
- [ ] 表格对齐、精度和单位一致，颜色对比足够。
- [ ] 整体风格一致，重点页与普通过渡页有合理区别。
- [ ] 修改过的页面已经重新检查，目录和页码同步更新。

## 可编辑性与使用

- [ ] 正文和标题可以直接修改，主体页没有被统一压成截图。
- [ ] 表格保留可编辑单元格。
- [ ] 要求可编辑的数据图和流程图符合约定，图表数据仍可访问。
- [ ] 图片、公式等不可编辑部分及原因已经说明。
- [ ] PPTX 与 DOCX 已用实际可用工具打开，未见缺失媒体或损坏提示；结构解析仅为补充，未完成的打开检查如实说明。
- [ ] 目标环境所需字体已知，存在的替换风险已经说明。
- [ ] 原始材料与原模板保留，最终文件另存了版本。
- [ ] 最终 PPTX 与独立 DOCX 讲稿确实存在，文件名、版本、页码与标题对应。

## Word 讲稿检查

- [ ] 逐页说明本页讲什么、重点是什么，语言适合实际口头汇报。
- [ ] 有图表时解释阅读顺序、参照、单位与具体观察；有公式时解释关键符号、项和作用。
- [ ] 过渡衔接与前后页面一致，最后一页不强加过渡，内容详略与汇报时间匹配。
- [ ] 不逐字复述页面，不把制作指令或内部检查字段写成讲稿。
- [ ] 已渲染并查看 Word 排版，标题、公式、表格和分页可读，没有截断和缺字；页码指向最终 PPT。
- [ ] 同步修改后的讲稿与最终 PPT 一致，备注没有被当作独立 Word 交付。

## 交付判断

文件损坏、缺页、错误的关键数据、严重遮挡或未满足必需可编辑性时，须修复后再称为可交付。事实未核实的版本标记为草稿或待补版。

主要方法关系未讲清、结果缺少必要读法或明显未达到指定参考风格时，也应先修改再交付。技术导出成功、没有溢出、能够编辑，不能单独证明内容和视觉质量通过。

达到要求且适用检查完成后交付 PPTX 和独立 DOCX；PDF、预览图和过程记录按需提供。简短说明剩余缺口、影响使用的限制及未执行的检查，不默认输出逐项验收报告。
